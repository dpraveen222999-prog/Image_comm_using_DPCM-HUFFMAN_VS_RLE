# Image_comm_using_DPCM-HUFFMAN_VS_RLE
This project compares DPCM with Huffman coding and RLE for image compression by generating compressed binary files, reconstructing images, and evaluating performance using compression ratio, MSE, and PSNR.

This project demonstrates a complete implementation of image compression using two classical techniques Differential Pulse Code Modulation (DPCM) combined with Huffman entropy coding, and Run-Length Encoding (RLE)—to highlight the differences between predictive and redundancy-based compression methods. After reading an RGB image, the DPCM module predicts each pixel from its neighbors and computes the quantized prediction error. This error sequence is encoded using Huffman coding, producing a compact binary bitstream saved as a .bin file, while the reconstructed image is saved as a JPEG using adjustable quality settings. The RLE module flattens the image into a 1D array and encodes consecutive repeated values as (value, count) pairs, which are also stored in a .bin file. Since natural images rarely contain long runs of identical pixels, RLE typically yields weak compression, making it a useful baseline against the more efficient DPCM-Huffman pipeline. The program automatically creates dedicated folders to store compressed and reconstructed outputs such as *_comm_dpcm.bin, *_recomm_dpcm.jpg, *_comm_rle.bin, and *_recomm_rle.jpg, ensuring clean project organization. It also computes and displays essential evaluation metrics—original bits, compressed bits, Compression Ratio (CR), Mean Squared Error (MSE), and Peak Signal-to-Noise Ratio (PSNR)—allowing users to objectively compare the effectiveness of both methods. This project serves as an educational and practical illustration of how predictive coding combined with entropy coding outperforms basic run-length techniques for natural images and acts as a foundation for understanding modern image and video compression standards.
